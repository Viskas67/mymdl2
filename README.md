# Sable (Dead by Daylight) → CS 1.6 player model

Исходники модели: `0.smd … 4.smd` (меши), `anims/` (анимации), `sable.qc`.

## Что было не так

1. **Длины костей в анимациях не совпадали со скелетом модели.**
   Скелет модели — CSO-шный (26 костей, с `L/R Calf_Sub`), уменьшенный до роста
   персонажа. А анимации в QC — стандартный набор CS 1.6 (111 sequence), сделанный под
   стандартный скелет: плечи шире (6.4 против 3.0), предплечье длиннее (11.4 против 8.7),
   шея длиннее (4.4 против 2.0), другие бёдра/голени. В GoldSrc позиции костей берутся
   **из анимации**, поэтому в игре каждую часть тела утаскивало к «чужому» суставу:
   вытянутые руки и плечи, оторванная шея, растянутые колени и запястья.
2. **Привязка вершин.** Куски колен (и пятно сзади на бедре) висели на `Calf_Sub`,
   которых в анимациях CS нет вообще — они не сгибались вместе с ногой и торчали шипами.
   Границы костей на руках/ногах/ботинках были рваные и разные слева и справа, часть
   волос была привязана к позвоночнику, детали аксессуаров — к разным костям.

`preview_before_after.png` — слева как было, справа как стало (рендер по SMD).

## Что исправлено

* `anims/*.smd` — полный набор анимаций CS 1.6 (639 файлов, все что нужны `sable.qc`),
  **перенесённый на скелет модели**: повороты костей взяты из анимаций, длины костей —
  из модели, движение таза масштабировано по длине ног, чтобы ступни стояли на полу.
* `0.smd … 4.smd` — исправлена привязка вершин (геометрия, UV и нормали не тронуты,
  поменялся только номер кости у ~600 вершин):
  * `L/R Calf_Sub` больше не используются (кости оставлены, вершин на них нет);
  * руки, ноги, перчатки и ботинки разрезаны ровно по суставам и симметрично;
  * волосы, ресницы и шляпа целиком на `Bip01 Head`;
  * каждый паук / кольцо / кулон целиком на одной кости.
* `sable.qc` не менялся.

## Как собрать

Положить рядом папку `textures/` со своими BMP и скомпилировать как обычно:

```
studiomdl.exe sable.qc
```

## Свои анимации

Если нужен другой набор анимаций (например, из другой модели) — их надо так же подогнать
под скелет, иначе модель снова поедет:

```
python tools/retarget_anims.py 0.smd <папка_с_исходными_smd> anims
```

Скрипту нужен только Python 3. Если ступни чуть проваливаются в пол или висят над ним —
добавить `--leg-scale 0.98` (больше — выше, по умолчанию считается сам, здесь 0.97).
